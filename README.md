# Analysing Pharmaceutical Sales Data
## About the Project
This project focuses on analyzing pharmaceutical sales data using Python and Machine Learning. I used Jupyter Notebook to explore historical sales data, understand sales patterns, visualize trends, and work on predicting future sales.
The project uses daily, hourly, weekly, and monthly sales datasets. I also developed an interactive dashboard using Antigravity to present the analysis and make the results easier to understand.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Antigravity

## Dataset
The project uses four datasets:
- `salesdaily.csv`
- `saleshourly.csv`
- `salesweekly.csv`
- `salesmonthly.csv`

These datasets contain historical pharmaceutical sales information at different time intervals.

## Project Objectives
- Analyze historical pharmaceutical sales data.
- Identify sales trends across different time periods.
- Compare sales across medicine categories.
- Use regression techniques to forecast future sales.
- Detect unusual sales patterns and outliers.
- Present the findings through an interactive dashboard.

## Work Done
### 1. Data Analysis
I used Pandas in Jupyter Notebook to load and explore the datasets, understand their columns, and analyze sales patterns.
### 2. Data Visualization
I created visualizations to compare sales across time periods and identify patterns in the available medicine categories.
### 3. Sales Forecasting
I explored regression-based machine learning techniques to predict future sales using historical data. Depending on the implementation, models such as Linear Regression, Polynomial Regression, and Support Vector Regression can be evaluated and compared.
### 4. Anomaly Detection
I worked on identifying unusual sales values, sudden increases, and unexpected drops to understand variations in sales behavior.
### 5. Interactive Dashboard
I used Antigravity to build an interactive dashboard for presenting the project's results.
The dashboard is organized into four sections:
- **Overview:** Key sales indicators and an overall summary.
- **Sales Trends:** Daily, hourly, weekly, and monthly sales analysis.
- **Sales Forecasting:** Historical sales and future predictions.
- **Anomaly Detection:** Unusual sales patterns and outliers.
## Project Workflow
1. Load the CSV datasets into Jupyter Notebook.
2. Explore and preprocess the data.
3. Perform exploratory data analysis.
4. Visualize sales trends using Python.
5. Apply regression models for sales forecasting.
6. Evaluate model performance.
7. Perform anomaly detection.
8. Use Antigravity to develop the interactive dashboard.
## Learning Outcomes
This project helped me gain practical experience in data analysis, data visualization, machine learning, regression-based forecasting, and interactive dashboard development.
